## 2026-08-23

| # | 決定 | 根拠 |
|---|---|---|
| D-01 | プロダクト名は **Ring** とする | 車輪・駅を囲む見えない輪・警告音の 3 つを兼ねる。応募フォームの作品名も Ring |
| D-02 | 本アプリは **サーバを持たない静的ブラウザアプリ** とする | 位置情報を外部に出さない／オフラインで動く／GitHub Pages で永続無償公開できる。判定は純粋関数でありサーバに置く理由がない |
| D-03 | 判定対象点は **画面中央固定のクロスヘア** とする。タップ選択にしない | 起動直後から答えが出ており、指を動かすと境界の存在が体感できる。位置情報を拒否しても全機能が使える |
| D-04 | 放置禁止区域は **Tier A（作図ポリゴン）と Tier B（駅指定リング）の 2 階層** で持つ | ポリゴンは全都分が存在しないが、都 Excel の駅別指定フラグは全都を網羅する。2 階層にすることで「代表区のデモ」ではなく「東京全域で答えが返る」サービスになる |
| D-05 | Tier A が覆う駅については **Tier B の推定を適用しない** | 精度の高いデータが常に勝つ。精密に「外」と判定した地点を粗い円で塗り潰さない |
| D-06 | データが無い場所では `outside`（停めてよい）と断定せず `unknown` を返す | 誤って「安全」と伝えることはユーザーに実害を与える。判定できないことは失敗ではない |
| D-07 | すべての判定に **出典・最終確認日・精度区分** を添える。出典を持たないデータは画面に出さない | このアプリは「撤去されるか」を答える。根拠のない断定は最大のバグ |
| D-08 | 精度 `estimated` の判定は `inside` ではなく `likely` として表示し、「推定」と主要部に明記する | 推定を事実として表示しない |
| D-09 | ETL の **出力 JSON をリポジトリにコミットする**。ビルド時に外部取得しない | 調査中に複数の公式 URL が 404・ホスト移転・curl 拒否を返した。外部依存のままだと区のサイト都合でサイトが壊れる |
| D-10 | 駐輪場の料金は **原文のまま保持し、数値化しない** | 区ごとに表記が全く異なる。誤った数値より正確な原文のほうが役に立つ |
| D-11 | 保管所の「今日開いているか」は、構造化済み (`open_rule`) のもののみ表示する | 推測して「開いています」と出すとユーザーが無駄足を踏む |
| D-12 | 基図は **地理院タイル（淡色）**、地図ライブラリは **MapLibre GL JS** | API キー不要・無償・日本の道路形状が最も正確。MapLibre の `raster-*` paint で基図だけを暗く落とせる（CSS filter だとオーバーレイまで着色される） |
| D-13 | スタイルは **CSS Modules ＋ デザイントークン**。ユーティリティ CSS フレームワークを使わない | 見た目が価値の一部であり、既定の見た目に引きずられたくない |
| D-14 | 外部ジオコーディング API を使わず、**同梱データに対する端末内検索** とする | オフライン動作とプライバシーの両方を満たす |
| D-15 | 実行時の外部通信は **地図タイルのみ**。アクセス解析を入れない | `NFR-4` / `NFR-5` |
