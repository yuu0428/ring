# Ring

**駅を囲む、見えない輪。**

自転車を停める前に、**その場所に停めたら撤去されるのか**を教えるブラウザアプリです。

> 「近くの駐輪場」を探すサービスは既にあります。Ring はその逆で、いま自分が立っている場所を判定します。

---

## なぜ作ったか

自転車を路上に停めてよいかは **放置禁止区域の内か外か** で決まります。区域の中なら警告のうえ即日撤去。取り戻すには自転車で 3,000 円前後、平日昼間に保管所まで行く時間がかかります。

ところが、この区域がどこなのかを事前に知る手段がありません。

- **境界が見えない** — 区域の境界は道の途中にあり、こちら側は大丈夫でも数メートル先はアウト
- **区ごとにバラバラ** — 千代田区は案内図、渋谷区は PDF、大田区は区域図。横断して見る方法がない
- **しかも動く** — 渋谷区は原宿・神宮前を 2025年10月に、渋谷駅周辺を 2026年4月に拡大した

既存の駐輪場検索は「安全な場所のリスト」であって、**リストの外側**については何も言えません。実際に人が停めるのは、駐輪場が満車のとき、近くにないとき、5 分だけ停めたいとき —— つまりリストの外側です。

**Ring は路上のどこを指しても答えを返します。**

---

## できること

| 機能 | 内容 |
|---|---|
| **停めていいかの判定** | 地図中央の十字が指す任意の地点について、放置禁止区域の内か外かを答える |
| **境界の警告** | 「ここから 12m 先は撤去対象」— 見えない境界までの距離を線と数字で示す |
| **代替の提示** | 撤去対象だった場合、近くの駐輪場を距離順に提示する |
| **区域変更の事前通知** | 区域が拡大される予定を、施行前に知らせる |
| **撤去された後の案内** | どの保管所に行けばよいか、開所曜日・時間・持ち物 |
| **根拠の開示** | すべての判定に出典 URL・最終確認日・精度区分を添える |

### 最大の障害と、この企画の中身

**放置禁止区域そのものは、機械が読める形では公開されていません。**

2026-08-23 時点で東京都オープンデータカタログを全文検索した結果、自転車の放置禁止区域のポリゴンデータは **1 件も存在しません**（唯一登録されていた杉並区のデータは URL が 404）。区は地図を持っているのに、PDF と案内図でしか出していない。

Ring はこれに 2 つの方法で対応しています。

1. **都の Excel に埋もれていた公式フラグを掘り起こした** — 「駅別放置自転車の状況」には駅ごとに「＊＝放置禁止区域に指定」が入っており、これは全都 702 駅を網羅する公式かつ機械可読なデータです。これを駅座標と結合し、東京全域のベースラインを作りました。
2. **推定であることを、推定として出した** — 生成した区域は駅指定フラグと駅座標から作った円であり、実際の境界の形とは異なります。アプリは判定のたびに「推定」と明示し、その区の区域図ページを 1 タップで開けるようにしています。
   公式区域図から作図したポリゴン（Tier A）は **現在 0 件** です。各区が区域を地図画像でしか公開しておらず、作図元となる公開データが存在しないためで、取り込み口だけ先に実装してあります（手順は [`docs/ZONE-DIGITIZING.md`](docs/ZONE-DIGITIZING.md)）。

あわせて、アプリ内に **オープンデータ公開リクエストの文面生成機能** を持たせ、区への正式な公開要請を誰でも送れるようにしています。**区がデータを公開すれば、Ring は推定ではなく正確な境界で答えられるようになります。**

## 開発

```bash
npm install
npm run dev        # 開発サーバ
npm test           # 判定エンジンのテスト
npm run build      # 本番ビルド
npm run etl        # オープンデータ取得 → public/data/*.json を再生成
```

## 技術

サーバを持たない静的ブラウザアプリです。位置座標は端末外に出ません。

- Vite 7 + TypeScript（strict） + React 19
- MapLibre GL JS v5 + 地理院タイル
- Turf.js（点-多角形判定 / 最近傍境界点 / 距離）
- Zustand / 素の CSS（デザイントークン）
- Vitest（判定エンジンの単体テスト）
- GitHub Actions → GitHub Pages
